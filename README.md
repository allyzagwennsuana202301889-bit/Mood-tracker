# BLIP! Mood Tracker (Expo / React Native)

Mobile mood tracker, AI companion chat, and foldered notes app based on the BLIP! Figma prototype.

## Quick Start (Expo Go)

1. Install **Expo Go** on your Android/iOS phone.
2. Start the dev server:
   ```bash
   npx expo start
   ```
3. Scan the QR code with Expo Go (works immediately in demo mode).
4. When ready for live Firebase + AI chat, fill in `.env` (see `.env.example`) and restart Expo (`npx expo start -c`).
